## 工艺、结构与上电

载板为 FR-4、2层、66 × 56 mm、1.6 mm厚、1 oz铜，绿色阻焊、白色丝印，目标表面处理为无铅喷锡。02版报告实际选择了有铅喷锡；重新分析时请使工艺设置与最终采用的工艺一致。

四个 Ø2.7 mm NPTH 安装孔中心为 (5,5)、(61,5)、(5,51)、(61,51) mm。23个元件放置、63个物理焊盘、接口及网络保持不变，现有 V0.2 Blender 外壳的数字几何依据仍适用。圆形机械孔的表示发生变化，不能据此声称源文件或原始铜层字节与02版相同；核对的是实际孔形与钻孔后铜图形。

电路和固件操作沿用 V0.2：USB烧录前断开外部5 V、拔下JP1/JP2/JP3；仅外供电时三个跳线均装上、USB不接；受控双电源联调时JP1拔下，确认雷达有电后执行 `radar on`。所有跳线在断电时切换。J3使用5 V自带限流、功率不超过0.5 W的灯板。完整步骤见仓库 `pcb/release_v02/README_交付与装配.md`，采购信息以本版BOM为准。

SMT预览需核对选料、封装中心及实际引脚方向；原生角度不等于贴片库零度。D1阴极向左，D2设计阴极向下，Q1单脚D在左、右下为G。D2实物色带与阴极对应仍需供方包装图确认。工艺边/定位点及后续手工焊接安排应由贴片方确认，本版单板没有新增工艺边或MARK。
