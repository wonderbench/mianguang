## 尚需确认的事项

1. 03第二份的8条`Pth无Pad`提示指向`Drill_NPTH_Through.DRL`。独立审计证实四个非镀铜机械孔源与导出一致，仍需DFM/CAM核对孔类型并记录处置；尚无平台豁免或零警告结论。
2. 另8条插件焊盘到贴片焊盘间距提示按既定工艺保留：14件SMT先回流、9件通孔/模块后手工装配。贴片方应确认手工焊接空间、工艺边/定位点；本版不作为波峰焊设计放行。
3. 03第二份已执行SMT DFM，但PDF不能证明全部14位号导入、选料和极性已逐项确认。04应重新分析并复核D1本体丝印提示是否消失，D1/D2/Q1方向按新极性表确认，D2实物阴极色带仍待供方包装图确认。
4. 两份03报告均选有铅喷锡；实际分析及最终加工设置应与目标无铅喷锡保持一致。

## 装配与上电

电路沿用V0.2操作要求：USB烧录前断开外部5 V并取下JP1/JP2/JP3；仅外供电时三个跳线装上、USB不接；受控双电源联调时拔下JP1，确认雷达有电后执行`radar on`。断电时切换跳线。J3接5 V自带限流、功率不超过0.5 W的灯板。外接件见本目录补充BOM，完整接线步骤见`../release_v02/README_交付与装配.md`；采购以本版完整BOM为准。
