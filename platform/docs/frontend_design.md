# 观测界面设计约定

本轮依据 Damir Sokolovsky（[@heydamir](https://github.com/heydamir)）的
[unslop](https://github.com/heydamir/unslop/tree/a6f121eee5f29c2f74976b75456feae8b66afb3a)
设计方法，参考其界面审计、间距、色彩、文字和图表规范，结合眠光的中文观测场景调整。
原方法采用 [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/)；这里记录的是本项目的应用与取舍。

## 方向

- 产品：值守人员核对床位最近上报、工作条件和本次绑定的趋势。
- 性格：安静、清楚、克制。
- 场景：需要反复查看、快速扫读的护理站观测工作台。
- 重点：床位身份、观测新鲜度与有效读数。
- 一致性：等宽数字、对齐读数、细分隔线，以及窄屏可读的刻度。

保留现有青绿配色、系统中文字体和总览 → 绑定详情的结构。页面继续使用 Django 模板、一个本地样式表与原生 JavaScript/SVG，不引入字体服务、图标库或图表依赖。

## 实施规则

| 部分 | 处理方式 |
|---|---|
| 层级 | 普通文字 400、标题与读数 500，品牌少量使用 600；去掉中文标题的装饰字距 |
| 间距 | 主要间距以 4px 为单位；按钮和输入框至少 44px 高，统一 8px 圆角 |
| 总览 | 三项摘要放在一个轻量统计区；五类连接计数独立换行，更新时间单独呈现 |
| 床位 | 读数使用等宽数字；原因、采集/接收时间保持 13px；状态同时有文字和颜色 |
| 趋势 | SVG 按实际宽度绘制，刻度保持约 13px；窄屏只显示首尾时间刻度，改变宽度用已有数据重绘 |
| 手机 | 指标单位独立成行，读数对齐；质量比例与分母逐项排列；输入框保持 16px |
| 操作 | 主操作使用青绿；快捷范围与导出降低视觉权重；支持跳到主要内容、当前位置与键盘焦点 |
| 动效 | 仅在允许动态效果时使用 150ms 的操作状态颜色过渡，不为观测值添加循环动画 |

## 业务呈现约束

30 秒观测过期、60 秒无新上报和每 15 秒刷新继续使用原逻辑；网络失败时旧读数也要独立过期。“需现场处理”与连接状态可能重叠，不能表现成互斥分类。

呼吸与心率分开作图，固定工程范围分别为 10–25 和 60–100 次/分；缺测或无效分钟断线，孤立有效点保留。查询时间仍为 UTC，上报完整度与有效点比例各自保留原分母。模拟数据、历史绑定、角色权限和导出限制均保留。

后续调整应先检查实际桌面与手机页面，再处理可复现的阅读问题；截图使用明确标记的合成数据。无需为样式变动扩充业务层测试或增加生产依赖。
